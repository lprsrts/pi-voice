# Reliability before local models

The first design bet on a local full-duplex model as pi-voice's distinguishing feature. We put reliability first instead: a voice that hands work over correctly and never claims what did not happen, on GPT-Live. We found no request for local full-duplex voice for coding agents (local demand is for dictation), local full-duplex models had weak or no tool calling on a Mac, and the complaints about voice coding agents were about hand-offs failing and cancelled work continuing. A local model stays an option behind the provider seam (ADR-0005), not the headline.
